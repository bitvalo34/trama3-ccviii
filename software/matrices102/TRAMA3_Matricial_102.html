Cómo se reciben dos bits

Se calcula p = a XOR b. Las tres columnas se leen juntas en cada tick. Tras tres ticks se resuelve el bloque; no se espera al CRC de la trama.

Los seis pilotos 010101 permiten excluir una columna para esa trama. Una pérdida posterior se trata como error desconocido; el próximo intento vuelve a comprobarla. No se mueve el significado de C0, C1 o C2.
